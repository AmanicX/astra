Astra turns natural language into work done on your machine. It is not a chat window bolted onto a desktop: it is a set of real tools that read, run, and report, and it hands you the decision whenever the stakes rise.

What it is. A desktop application for Windows and Linux. A Rust core owns every capability, and the interface is a typed client over a command bridge, so the assistant can only act through tools you can inspect.

What it does. System control, file work with backups, web research, screen awareness, and coding workflows. Every tool declares a risk tier before it runs.

How it stays yours. Conversation history and memory live in a local SQLite database. Provider keys live in the operating system credential store, never in the database or the logs.

Where it runs. Built for Windows 11 with the WebView2 runtime, with native packages for Fedora and RHEL and a portable image for Arch.

Questions

Is Astra a chat app?

No. The conversation is the interface, but the substance is a set of tools that act on your computer. It can read system information, launch applications, change supported settings, work with files, search the web, and capture the screen.

Which models can it use?

Astra supports Groq, OpenAI, any OpenAI-compatible endpoint, a local Ollama server, a custom provider, and an offline test provider. The default chat model is gpt-oss-20b, and the default vision model is Llama 4 Scout.

Where do my API keys go?

Into the operating system credential store: Windows Credential Manager or the Linux Secret Service. They are never written to the database, and never written to logs.

Can it change files without asking?

Consequential actions are declared at a high risk tier and require an action-specific approval in the native shell. Lower-risk reads and supported settings can run directly. The model proposes; the shell decides.

Does it work offline?

Partially. With the offline test provider you can run the whole interface with no key and no network. Local models can be used through Ollama. Web research and cloud models need a connection.

Which platforms are supported?

Windows 11 is the primary, best-tested target. On Linux, Fedora and RHEL have a native package and Arch has a portable image. The Linux builds are early and less tested than Windows.

Get Astra

Astra is an early pre-release. Everything below comes from the official GitHub releases.

Windows

Windows 11 or later, with the WebView2 runtime.

Download the installer

Choose the NSIS .exe or the .msi on the releases page.

Linux

Fedora and RHEL use the RPM package. Arch and other distributions use the portable image.

Download from releases

Or build and install from source:

git clone https://github.com/AmanicX/astra.git
cd astra
./scripts/install-arch.sh     # Arch and CachyOS
./scripts/install-linux.sh    # Fedora and RHEL
