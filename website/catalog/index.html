Astra Architecture & Changelog

Technical specifications, system module breakdowns, and pre-release tracking for the Astra local-first AI assistant.

Release v0.1.0-pre.1 (Initial Public Pre-release)

October 17, 2026

First public testing build introducing the Rust command bridge, Tauri v2 shell, native permission engine, and dual-window React frontend.

• Permission Engine: Implemented typed risk classification (low/moderate/high) with modal confirmation gates.
• Voice Pipeline: Integrated Groq Whisper transcription and neural Edge TTS with offline system voice fallback.
• OS Automation: Native tools for audio, display brightness, networking, file management with backups, and authorized shell execution.
• Local Memory: SQLite conversation and entity memory engine storing session history and preferences locally.

Roadmap to v0.2.0

Development is actively focused on expanding Linux hardware validation, deep file indexing, and autonomous coding workflows.

  • Wayland native screen capture bridge for Niri & Hyprland
  • Direct Eva Linux integration package (astra-assistant)
  • Enhanced MCP (Model Context Protocol) tool provider server
